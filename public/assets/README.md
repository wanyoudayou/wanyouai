# 站内静态资源

放在本目录的文件随站点一起构建部署，通过 `/assets/<文件名>` 直接访问。

- `hero-cloud-glass.svg` 与 `hero-terminal-wave.svg` 分别是浅色、深色模式的默认首页背景，适用根目录 MIT 许可证。
- 新装站点不预设头像或 Logo；未配置时分别显示站主名称和站名的首字标。
- 站主自己的横幅、头像、Logo 和文章图片可在后台上传到[素材库](../../docs/contracts/media-library.md)，由 Supabase Storage 提供并通过选图控件复用。
- 需要与代码一起维护的静态图片也可放在本目录，并在对应配置中填写 `/assets/<文件名>`。文件名使用小写字母、数字和短横线，保留素材的来源与许可说明。
