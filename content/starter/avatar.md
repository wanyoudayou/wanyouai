# 站主 AI 分身

站主分身是站内的知识库问答：访客在首页、右栏或手机底部的「分身」入口提问，分身只依据本站已发布的内容回答，并附上来源链接。它不是通用聊天机器人，资料不足时直接说明，并引导访客浏览目录或查看名片页。

## 分身如何回答

1. 访客提问后，系统先在本站知识库中检索相关段落。知识库包含已发布与暂停的文章，以及站主编辑确认的公开问答；草稿、归档和私人会话不进入。
2. 检索结果逐条按访客当前的阅读权限复核。只有对方有权阅读的正文才交给模型；未解锁的付费内容只给出标题、权限说明和试读链接。
3. 没有可用资料时不调用模型，固定说明资料不足，不编造答案。
4. 回答附来源，界面常驻「AI 生成 · 仅供参考 · 合作请转人工」。访客可在对话中转人工留言，站主在后台查看。

文章页的「向分身提问」和 `@引用` 会优先使用指定文章，但同样受权限约束。访客询问“你是谁”时，分身说明自己是站主的 AI 分身，并引导访问名片页。

## 开通步骤

全部在「站点设置 → AI 设置」完成，无需修改部署变量：

1. **生成连接**：选择模型平台，填写接口、模型与 API Key，保存后做一次连接检查。
2. **向量连接与知识库**：配置向量模型，确认文字发送范围与费用后建立索引；生成完成后由站主确认启用。
3. **分身指令**：可先载入推荐模板，再按自己的角色、语气和业务引导修改；支持 Markdown 预览，保存后生效。固定的权限与引用规则不可编辑。
4. 勾选启用分身并保存。需要匿名访客提问时，再配置人机验证并打开「允许匿名提问」。

详细字段和排错见[AI 设置与站主分身](../../docs/deployment/guide.md#64-ai-设置与站主分身可选)与[知识库构建与日常更新](../../docs/deployment/guide.md#66-知识库构建启用与日常更新)。

## 日常运营

- **内容更新后同步**：发布或修改文章后，在知识库点击「同步内容变化」并确认切换。旧版文字立即退出检索，新内容在切换后使用。
- **整理公开问答**：原始会话只对提问者和站主可见。值得公开的问答由站主另行编辑、脱敏后发布，发布后可进入检索；撤回只删除公开稿。
- **检查检索效果（可选）**：准备真实问题，标注应命中的文章，查看前五个候选是否包含答案；未命中时补充文章的答案、标题和上下文，再同步比较。
- **控制用量**：注册用户、订阅用户和匿名访客分别有每日次数，站点另有月度上限；命中缓存不消耗生成次数。月度次数不等于供应商账单上限，请同时在模型平台设置预算。

分身未启用、连接不可用或知识库未就绪时，前台自动隐藏入口，不会退回通用聊天。
