# Skill 发布与在线运行

Skill 是可交付的 AI 技能包：一篇公开介绍，加上一个私有 ZIP 包（`SKILL.md`、参考资料与可选脚本）。访客读介绍了解用途；取得权限后既可以下载安装到自己的 Agent 工具，也可以直接在网页里在线运行。

## 两种使用方式

| 方式 | 适合 | 说明 |
|---|---|---|
| 下载安装 | 有 Claude Code 等支持 Agent Skills 的本地工具 | 下载 ZIP，或生成 15 分钟有效的安装说明交给本地工具；安装前核对版本与 SHA-256 |
| 在线运行 | 不想安装、先试用 | 在介绍页右栏点击「切换成在线测试」，直接输入任务；手机从底部 SKILL 入口打开 |

在线运行由站点后台保存的生成模型执行 `SKILL.md` 的指令，并可通过受限的读文件工具读取包内参考资料。包内脚本只供下载后在用户自己的环境使用，网站不会执行脚本。

## 发布一个可在线运行的 Skill

1. **准备私有存储**：在 Supabase 创建固定名称的私有桶 `skill-packages`（20 MB、仅 ZIP）。只需配置一次，步骤见 [Skill 发布与使用](../../docs/deployment/skills.md)。
2. **写介绍**：后台「内容管理 → SKILL → 新建 Skill 介绍」，写清用途、需要用户提供什么、交付什么。介绍全文公开。
3. **上传版本**：上传 ZIP 或文件夹，填写版本号与更新说明；选择当前交付版本并设置价格。`0` 表示登录后免费，收费 Skill 复用订阅与单独购买。
4. **开启在线运行**：先在「AI 设置」保存并检查生成连接，所选模型需支持工具调用；再勾选「启用在线文本对话」，填写使用引导并保存。不需要建立全站知识库。
5. **自测**：用不含私人资料的任务在前台试运行，确认回答格式、参考资料读取与额度提示正常。

## 运行规则

- 切换下载与在线模式不调用模型；发送任务才调用并计入额度。输入草稿在本页切换和关闭抽屉后保留，刷新可恢复已提交的对话。
- 已有对话继续使用创建时的版本，新对话使用当前交付版本。上传新版本后需重新选择交付版本才会替换。
- 核心 `SKILL.md` 超过 32 KiB 时仍可下载，但不能在线运行；把补充材料移到 `references/`。
- 结果不确定时先点「查询本轮状态」，它只读取已保存结果，不会重发；不要连续重复发送。
- 暂停 Skill 后停止新售，已有权益按保留规则继续使用；已下载的文件无法远程收回。
