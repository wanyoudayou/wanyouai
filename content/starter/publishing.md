# 首次设置与内容发布

## 认领站主与载入示例

完成网站部署和邮箱登录设置后，从 `/admin` 使用 `OWNER_EMAIL` 指定的邮箱登录，首次验证成功即认领站主。在「维护 → 部署检查」检查基础配置，按需要载入使用指南与收费方案，也可选择空站开始。

示例导入后归站主管理，升级代码不会覆盖已经编辑的指南。随后在「站点设置 → 站主名片」填写站名、介绍与联系方式。

## 新建文章

进入后台的「内容管理 → 文章 → 新建文章」，填写标题、网址标识和阅读权限，再编辑或导入 Markdown。图片可直接上传到素材库并插入正文，也可从素材库选择已有图片。

保存待发布修订后查看匿名预览，确认公开范围再发布。保存、审核与发布均使用相同发布管线。

## 发布到专辑

进入「专辑」，创建或打开手册或活动，在章节列表中新建文章，工作台会保留所属专辑。文件夹导入只读取根目录 Markdown，直接放入专辑根目录；子目录和其他文件忽略，缺少的图片在编辑器补齐后再发布。

在专辑设置中统一保存详情、价格和导航，然后从「待发布更新」核对预览和权限，一次发布全部或选中的章节。新专辑可同时选择本批公开 README 并勾选上架；任一所选文稿有错误或冲突时，本批不会部分上线。

同一篇正式文章与它的新修订只占一行；例如「已发布 v3 · 待审核 v4」，审核前线上继续提供旧版本。

## 阅读权限

公开预览应足够说明内容价值。付费正文不会因为隐藏导航而受到保护，必须设置正确权限，并以匿名、注册与已购身份分别核对。

受限文章用编辑器的「插入付费墙」或 `⌘/Ctrl + Shift + P` 划定预览。第一个独立付费墙标记决定预览截断位置；多个标记不阻断发布，后续标记不再扩大预览。没有标记时，受限正文不提供试读；公开文章始终全文公开。

准备离开编辑器前保存或下载草稿。网络结果不明确时先确认修订或发布状态，避免盲目重复提交。

## 使用 Obsidian 或发布 Skill

桌面 Obsidian 的 OPC手册管理器只上传手册根目录 Markdown 和实际引用图片，支持共享附件。先比对，再上传线上草稿，最后到网页后台设置权限和审核发布；线上状态会同步回插件，全部相同时无需上传。安装与配置见 [OPC手册管理器](../../docs/deployment/obsidian.md)。

Skill 在独立入口管理公开介绍和私有版本包，使用 `skill-packages` 私有桶；包内脚本供下载，网站只提供可选文本对话。配置与发布见 [Skill 发布与使用](../../docs/deployment/skills.md)。
