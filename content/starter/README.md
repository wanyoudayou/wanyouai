# 默认使用指南的来源

首次站主设置可载入一个公开手册和一个收费方案页。手册固定为八篇，网址与导入标识保持稳定；站主导入后可自行编辑、管理导航与发布状态。

| 手册章节 | 维护来源 |
|---|---|
| 功能与使用方式 | [功能概览](overview.md) |
| 部署准备 | [部署指南](../../docs/deployment/guide.md)第 0、1 节 |
| Supabase 初始化 | 部署指南第 2 节：创建项目、安全设置、安装与图片桶 |
| 网站部署与邮箱登录 | 部署指南第 3–5 节：Vercel、域名、Auth 与 SMTP |
| 首次设置与内容发布 | [内容发布](publishing.md)：认领、编辑、图片、整辑发布、Obsidian 与 Skill |
| 名片、导航与收费方案 | [站点设置](navigation.md) |
| 可选功能与部署检查 | 部署指南第 6.1–6.7 节 |
| 升级与日常维护 | 部署指南第 7 节；详细备份恢复使用原运维文档 |

`manifest.json` 明确列出来源和章节标题。运行 `npm run starter:build` 生成 `src/generated/starter-content.json`；`npm run contracts` 检查生成内容没有漂移。生成器只读取白名单公开来源，不扫描内部文档、环境文件或本地归档。

已经包含在手册内的来源链接转换为站内章节和阅读页锚点；完整 SQL、邮件模板及补充操作文档链接到源码。代码示例中的链接保持原样。`pricing.html` 提供可编辑的收费说明，真实方案由 `cp-pricing` 组件读取站点配置。

更新这些来源只改变以后载入的模板，不覆盖已安装站点中的手册或收费方案。未完成的旧模板导入遇到内容版本变化会停止；先用原代码版本完成导入，再升级，不重置检查点或覆盖已有文稿。
