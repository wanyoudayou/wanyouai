# AI 生成自定义页面

当 Markdown 不够表达时，例如落地页、专题页、关于页或收费说明，可以用自定义页面。站主用一句话描述需求，AI 生成符合本站视觉的初稿；站主在编辑器里预览、修改并继续让 AI 迭代，满意后再保存发布。

## 可以用在哪里

| 位置 | 地址 | 说明 |
|---|---|---|
| 独立页面 | `/p/<网址标识>` | 公开页面，可加入左侧导航或页脚链接 |
| 首页自定义区 | 首页 Hero 与内容区块之间 | 在「站点设置 → 站点配置」开启，可从任一页面复制内容后独立编辑 |
| 名片自定义区 | 名片页右列 | 使用紧凑卡片样式 |

三处共用同一套安全 HTML 与站点视觉，浅色、深色和手机布局自动适配。

## 与 AI 协作

1. 在「独立页面」新建或打开页面，进入编辑器。
2. 在 AI 生成框描述页面内容与结构，例如“一个订阅权益说明页，含三种身份对比卡片和行动号召”，点击「生成初稿」。
3. 切换预览检查效果。可以直接改 HTML，也可以把当前 HTML 和修改意见一起交给 AI，基于现状再生成一版。覆盖编辑器内容前会先确认。
4. 生成结果只是草稿：不会自动保存、发布或修改站点配置。确认后保存，再发布。

AI 使用「AI 设置」里的共享生成连接，未完成连接检查时生成按钮不可用。生成器不会编造站主身份、客户评价、统计数字、价格或链接；资料不足的模块会直接省略，请在描述中提供真实信息。

## 块级元素

页面由站点预定义的 `cp-*` 语义类组成，常用的有：

- **分节与排版**：`cp-section`、`cp-h1`／`cp-h2`／`cp-h3`、`cp-lead`。
- **卡片与网格**：`cp-grid-2`／`cp-grid-3` 搭配 `cp-card`，用于并列的特性或方案。
- **提示与行动**：`cp-callout` 说明注意事项；`cp-cta` 为主要按钮，`cp-cta-secondary` 为次要按钮。
- **图标**：`<span class="cp-icon" data-icon="book-open"></span>`，只能使用白名单内的线性图标，旁边需保留文字。
- **图片**：在编辑器中「插入素材图片」，从素材库选择。

另有两个实时业务组件，HTML 中只放空占位：

- `<div class="cp-pricing"></div>`：显示当前收费方案、订阅价格与购买入口。
- `<div class="cp-subscribe"></div>`：只显示订阅入口。

价格、开通状态和权益都实时读取站点配置，页面 HTML 不保存价格快照。

## 安全边界

保存和显示时都会净化 HTML：不允许脚本、内联样式、表单、嵌入页面、事件属性和白名单外的类名。链接仅限 https、邮件和站内地址。自定义页不进入 `/llms.txt` 与 `/card.json`。需要交互或数据的功能请使用下一章的代码栏目。
