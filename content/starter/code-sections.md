# AI 生成代码栏目

代码栏目是嵌入本站的交互式子项目，例如练习室、计算器、可视化教程或小工具。它运行在 `/lab/<栏目名>`，与主站共用左侧导航、浅深主题、组件与设计规范，并直接使用本站的登录与订阅权限。栏目代码可以完全由 AI 编程助手生成，也可以把已有的小型网页项目迁移进来。

## 选择合适的形式

| 需求 | 做法 |
|---|---|
| 文字、图片与排版 | 文章或自定义页面 |
| 需要交互、状态或计算，并希望与站点融为一体 | 代码栏目 |
| 技术栈不同、需要自有后端或数据库 | 单独部署，在导航中添加外部链接 |

## 用 AI 生成栏目

仓库内置了供 AI 编程助手使用的栏目技能（`.claude/skills/new-section/`）。在本地仓库中打开 Claude Code，直接描述需求，例如“新建一个 GitHub 协作练习栏目”或“把这个 Vite 小项目迁移成栏目”。助手会：

1. 确认栏目名、标题、简介、图标和档位，生成栏目目录与路由；
2. 只在 `src/sections/<栏目名>/` 内编写功能，复用站点组件、颜色变量与本地进度存储；
3. 运行检查（样式守卫、类型、构建、体积预算与浏览器测试），全部通过后在你确认时提交 PR。

栏目只能通过站点提供的接口使用主站能力：不能读取付费正文、会话、邮箱或权益明细，不能使用环境变量、服务端写入或第三方脚本，样式只能使用站点颜色变量。这些规则由检查脚本自动强制。

## 上线与权限

1. PR 通过检查并合并后，网站随部署更新。
2. 在「站点设置 → 导航」添加该代码栏目，可放入父级目录。
3. 选择访问级别：免费、登录可见或订阅可见。判定在服务端完成：未登录访客先登录，未订阅用户看到订阅入口。
4. 启用并保存导航。未加入或未启用的栏目对访客返回 404，站主可以预览。

上线、下线只需在后台切换，不必重新部署。手机目录中隐藏代码栏目并提示在电脑上访问。

## 注意

- 栏目的前端代码和其中的数据会下发到有权访问的浏览器，不能用来保存必须保密的内容。
- 如果仓库公开、但希望保留栏目源码，可以在私有仓库中开发和部署，再导出不含栏目的公开版本。维护流程见仓库中的版本与发布说明。
- 删除栏目同样交给助手处理，部署后在导航中移除对应项目。
