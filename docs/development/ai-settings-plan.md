# AI 配置与知识库工程规则

本文规定统一 AI 与知识库的工程边界。部署操作见[部署指南](../deployment/guide.md)，验收完成情况见[发布状态](release-status.md)；离线协议测试不代表真实供应商与部署验收已通过。

## 1. 产品边界

一个站点使用一个 AI 配置页面，集中管理共享生成连接、知识库连接与索引、分身指令、功能开关和运行检查。前台分身是本站知识库问答，不提供脱离本站资料的通用聊天。

共享模型连接服务两项任务：

| 任务 | 使用的指令 | 所需条件 | 结果 |
|---|---|---|---|
| 前台分身问答 | 系统固定约束＋站主可编辑指令＋已验权知识库片段 | 分身开关开启、生成与语义检索连接可用、知识库索引就绪、访问与调用限制通过 | 回答与允许公开的来源链接 |
| 后台自定义页面生成 | 项目维护的固定页面设计与结构提示词＋站主本次需求 | 站主身份、共享生成连接可用、调用限制通过 | 可编辑草稿，站主另行保存／发布 |

关闭分身、知识库为空或检索故障，不关闭后台自定义页面生成。后者不读取分身的站主指令、聊天记录或知识库正文。共享连接不共享任务提示词或任务上下文。

## 2. 后台配置与存储

入口为 `/admin/ai`，导航名称为「AI 设置」。原 `/admin/avatar` 保留兼容跳转。页面分区：

1. **共享生成模型**：协议、接口根地址、模型标识、API Key、连接状态。
2. **知识库与语义检索**：向量连接、模型、索引状态、重建与失败恢复；属于分身的必需依赖。
3. **站主分身**：对外开关、匿名提问、站主指令和调用限制。
4. **自定义页面生成**：共享连接状态、固定规则说明与编辑器入口，不提供系统提示词编辑框。

日常模型配置均在后台管理，保存后用于新请求，无需重新部署。连接配置与凭据由服务端受控读取，不加入匿名可读的 `site_config` 投影；管理页只返回必要配置及密钥存在状态，不回填完整密钥。配置与凭据同事务保存，使用版本检查阻止并发覆盖，不产生部分保存成功的连接。

同一供应商同时提供生成和向量能力时，站主可显式选择复用连接凭据；仍分别指定模型和用途。不同供应商不自动复用密钥，缺失向量配置不隐式借用生成密钥。改变调用目标须重新校验凭据绑定。

不新增供应商市场、自动切换或无界重试。旧环境变量仅提供显式迁移入口；迁移成功后后台配置成为唯一生效来源，避免多套配置静默覆盖。

## 3. 协议适配

生成连接覆盖 OpenAI 兼容 Chat Completions、OpenAI 兼容 Responses、Anthropic Messages，分别适配鉴权、请求结构、流式事件、终止状态与用量；不以替换 URL 冒充协议支持。

通用协议解析使用 AI SDK Core 与直接供应商适配器，统一经项目的安全出站层访问后台保存的连接。`generate`／`embed` 为业务调用入口，权限、账本、终止状态和向量校验由项目控制；关闭自动重试与外部遥测，不要求网关账户或 SDK 专用环境变量。接入、升级与回退检查见 [AI SDK 接入说明](ai-sdk-migration.md)。

向量连接使用 OpenAI 兼容 Embeddings 协议。供应商支持某种生成协议，不等于提供向量模型。现有索引为 1024 维，须校验返回维度、数量、有限数值和响应容量；模型身份与索引一致后才能投入检索。

首个兼容目标为硅基流动 `BAAI/bge-m3` 原生 1024 维，接口、合成检查工具、完整索引任务、模型切换及验收详见 [Embedding 实施规格](embedding-implementation.md)。该规格区分官方已核实能力、离线测试与待授权的真实账户验证；不以协议相似推断供应商兼容。

问答与页面生成共用生成适配器及出站请求保护，各自提供任务指令和输出限制。页面生成保留现有 `customPageMessages` 与 `prepareGeneratedPageDraft` 管线。

## 4. 提示词边界

### 分身

站主可编辑身份、服务范围、表达方式、回答结构与转人工方式，提供默认内容、恢复默认与测试入口。系统固定约束可查看但不可删除，包括基于本站资料回答、资料不足不编造、资料不作为执行指令。

推荐模板使用 Markdown 组织角色、职责、语气、资料不足处理、业务引导和来源规则。模板由源码维护，站主显式载入；非空草稿覆盖前确认，载入可撤销，保存前不改变线上配置。编辑／预览共用同一原文；预览不执行 HTML、不自动加载图片、不调用模型，任何视图保存均提交 Markdown 原文。加载模板不授予工具、扩展知识范围或替代代码验权；已有指令不随应用升级自动覆盖。

正文权限、无命中停止生成、知识库就绪与调用限制由代码执行，不依赖模型服从提示词。提示词保存在非公开配置，不包含密钥或机密资料；不能承诺模型绝不复述指令。修改站主指令或系统规则后，回答缓存必须失配。

### 自定义页面

生成代码的系统提示词由项目源码维护，站主不可编辑、替换或通过请求参数覆盖。站主只填写本次页面需求和选择页面／区块用途。

固定规则包含当前双色设计规范、`cp-*` 结构、允许标签与图标、真实价格占位组件，以及输出格式。固定提示词不替代代码检查：生成草稿须通过结构校验与净化，保存和读取继续净化；不执行模型生成的脚本，不自动发布，不编造价格或可支付动作。

## 5. 知识库与对外状态

知识范围沿用已发布内容与站主审核的公开问答稿；原始私人会话不进入索引。发布、修订与权限变化须保持索引及授权一致；变更向量模型后，旧向量不得与新查询向量混用。

| 状态 | 前台行为 | 后台操作 |
|---|---|---|
| 站主关闭分身 | 隐藏提问入口、分身按钮与聊天面板；问答接口拒绝调用 | 保留配置、内容与索引，可继续维护 |
| 缺少连接、没有可用资料或索引未就绪 | 不开放分身问答，不回退为通用聊天 | 指明缺项、索引状态与下一步 |
| 分身就绪 | 按匿名／登录与权益规则提供知识库问答 | 展示配置、索引及调用状态 |
| 本次无相关命中 | 提示未找到相关资料，不发起生成调用 | 不将单次无命中误判为全站无知识库 |
| 检索临时故障 | 提示暂不可用，不绕过检索生成 | 保留站主开关，区分故障与空库 |

隐藏分身不移除阅读目录或普通内容导航。即使绕过界面直接请求 API，也必须执行相同的就绪、权限和调用检查；访客页面只获得必要的可用状态，不获得连接凭据或私有配置。

## 6. 出站安全与调用控制

- 后台保存接口地址之前验证受信目标；实际调用同时约束 HTTPS、内部网络访问、DNS 与重定向，凭据只发送至绑定目标。普通访客、提问或知识库文字不能决定调用地址、协议或密钥。
- 服务端先按请求者身份验权再组装生成上下文。未购内容仅提供允许的标题、预览与链接；不因站主指令而扩大正文可读范围。
- 生成、检索和页面生成均受期限、响应容量与调用控制约束。检索请求的频控独立于生成配额，缓存命中不消耗生成次数；避免在判定生成超额之前仍可无限调用向量服务。
- 启用或重建向量索引前说明文字发送范围与费用：发送内容可能包含付费正文；向量供应商获得的是文字输入。连接检查使用最小测试输入，不静默发送实际文章。
- 统一异常脱敏和用量记录，区分分身与页面生成；不记录凭据、完整请求头、私人正文或供应商原始错误。

## 7. 实施顺序与验收

1. 私有配置与原子保存、迁移入口、共享生成适配器及网络保护。
2. 单一 AI 设置页与兼容路由；分身可编辑指令、页面固定指令的隔离。
3. 知识库索引状态、模型一致性、可恢复重建与前后台就绪检查。
4. 统一调用控制、部署检查、文档与回归，完成受影响的部署验收后合入。

数据库只追加迁移，同步 install／verify 生成工件；新装与既有实例迁移分别验证。迁移不自动发送文章、调用付费接口或开启分身。

验收必须覆盖：非站主拒绝、凭据不进入公开输出、保存冲突、迁移重放、多协议流式与非流式、受信目标及重定向、向量维度与索引失配、空库与单次无命中、未购正文保护、提示词修改后的缓存失配、关闭分身后的全端入口及 API、分身关闭时页面生成仍可用、页面指令覆盖被拒及不合规输出净化。

每批运行工程必需检查及对应回归；本地替身不代替真实供应商兼容性与云端验收。真实付费调用、邮件和支付按必要范围显式操作，不为配置读取检查自动触发。

## 8. 配置、启用与诊断交互

主流程为「准备内容与连接 → 选择索引任务 → 建立索引 → 确认启用 → 使用与更新」。只展开当前必需步骤，连接已保存时折叠；当前状态、下一步及停止原因在就地提示中明确呈现。

- 首次初始化处理全部有效来源；兼容增量同步复用摘要、模型与预处理一致的向量；重建不复用。扫描和批处理持久化，刷新只读，不自动恢复付费调用。
- 全部当前来源覆盖、扫描完成、无待处理／租约／失败项、连接已验证且匹配后，站主可直接确认启用。不要求诊断报告、题数或分数；确认绑定来源版本、连接及代际，在数据库中原子记录并切换。
- 新机制固定初始阈值 0.5，兼容同步继承原活动阈值；诊断题目与标注不调整运行阈值。阈值只是检索策略，正文授权仍由代码执行。
- 「可选：检查检索效果」可在启用前后打开。手工 1–100 题，自动出题使用共享生成连接；未核对的题不可发送。来源选择器显示标题，技术标识折叠；不呈现训练／验证分组。
- 编辑、发送确认、运行和报告互斥。错配优先并高亮，原题／原始命中保留；采纳经核对的来源只加入草稿。正确失败题应保留，用同一组问题对比正文、分块或检索实现的改进；不以改题提高分数冒充效果改善。
- 取消编辑只影响未提交草稿，已修改时二次确认；下载草稿不调用模型。存在草稿时先结束编辑再切换，避免丢失输入。旧报告仍可读，旧启用接口要求刷新，不以历史分数授予切换权。
- 自动出题、问题检索和单题回答分别确认发送范围及费用；响应未知时保留已确认进度，手动重试另行确认可能重复计费。单题回答默认匿名权限，同正文授权管线，不写真实会话。
- 日常同步完成后可直接确认使用；建议在模型、检索规则或重要内容改变时用固定问题对比，任何一次检查都不认证未来问题的效果。

回归覆盖无报告／低命中启用、缺确认拒绝、过期来源／连接／不完整拒绝、权限隔离、原始结果不可变、草稿保护、阈值不随改题变化、未知请求不重放及浅深主题和 320px 布局。迁移不自动启用、生成向量或调用外部模型。
