# 安全审查摘要

本页记录当前必须保持的安全边界与验证方法。逐日调试和单次交易资料已本地归档；发布判定见[发布状态](release-status.md)。

## 安全边界

- 正文读取受 RLS 与服务端授权共同限制；分身注入再次校验生命周期与权益。缓存按账户及实时授权上下文隔离。
- 原始对话保持私有，公开稿独立存储并经站主确认；公开编辑不自动带入原始回答。
- 建单由数据库复核商品与金额并原子复用待付单；回调、返回查单和定时查单共用事务结算。商户编号、金额和流水必须匹配，事件与订单绑定且重复开权益被拒绝。
- 权益邮件与支付同事务入箱；worker 独立领取、固定重试载荷，超出幂等安全窗口停止自动发送。
- 首次站主认领限定已验证邮箱，数据库约束唯一站主；会话异常失败关闭。后台诊断与导出逐次验权，秘密不回显。
- 安装显式设置 RLS、policy、GRANT，撤销默认维护权限；恢复后收口 ACL。迁移源、生成物及旧库升级做目录等价与数据保留验证。
- 分身额度原子预留，模型调用与导出读取有期限和容量边界；后台导出读取失败不提供部分结果。
- 后台文档与专辑投影为调用者权限并显式检查站主；用户聚合函数仅服务端可执行，调用前验证站主。列表不输出正文或待审核快照。
- 示例初始化同时检查已发布和仅有待审核修订的文档地址；冲突时不创建示例对象。章节经标准发布事务逐步提交，全部成功且没有被编辑后才启用默认导航。
- 自定义页面生成只返回草稿；结构提示词、Lucide 图标槽和方案占位符仍受保存/读取净化与服务端交易权威约束。

## AI 与知识库复核范围

AI 连接与调用账本、索引和评测表均启用 RLS 并撤销浏览器表权限；站主网关只返回显式元数据投影。内部来源触发器位于非暴露 schema、固定 search_path，三类 API 角色无直接执行入口。唯一面向登录用户的用量函数不接收用户 ID，仅按 `auth.uid()` 聚合本人记录。

出站固定受信 origin，检查 DNS 全部 A/AAAA 并把已验证地址绑定到实际 TLS 连接；不跟随重定向。凭据与不可变目标版本绑定，协议分开适配鉴权及完成状态。知识库写回复核来源摘要与租约；活动代际与其向量模型绑定，生成上下文经代码验权。

发布验证分别记录隔离数据库与真实 PostgreSQL 并发、代码复核、供应商检查及部署验收。离线通过不代表真实供应商或云端配置通过；具体版本与证据范围见[发布状态](release-status.md)及对应版本的 Release 说明。

## 升级与初始化

后台查询、示例初始化与 AI 页面生成保持原有站主权限。初始化同时检查正式内容与待审核修订，地址冲突时拒绝覆盖。迁移通过新装／升级等价、角色授权、半成品匿名不可读、价格校验、重复结算和初始化重放回归验证。

初始化与其他编辑入口同时首次占用同一地址的交错尚未作专项并发证明，不能据此宣称该交错已验收。地址冲突必须由数据库约束拒绝，调用者保留输入并重新查询；不得用覆盖或自动换地址掩盖冲突。

## Skill 与手册同步边界

- 公开介绍和私有包分开；Storage 使用私有桶与限制性策略，宽泛的图片读取策略不能放行 Skill 包。每次交付和对话重新验权，安装授权只存摘要并限制版本、期限与兑换次数。
- ZIP 按实际解压字节校验容量、CRC、路径和凭据材料；包内脚本只能下载，在线执行器只能读取当前版本白名单文本。核心指令不静默截断，模型输出不执行 HTML 或自动加载图片。
- Skill 会话与用户及不可变版本绑定；数据库串行化同一用户的提交，单会话只运行一轮，每次模型派发进入现有额度账本，结果未知不自动重试。
- Skill 的 JSON 输出使用供应商原生格式，不允许 SDK 用隐式工具代替；SDK 解析后仍校验动作与绑定包路径，格式合规不扩大权限。失败不自动回退重发，错误不包含原始模型响应。
- 插件凭据只能维护手册及引用图片；改域名清除凭据选择，客户端验证域名绑定并拒绝重定向。暂存、发布和重命名复用版本校验与发布事务。
- 转换保留旧 ID、订单和权益；只有原本公开的同专辑 README 能成为公开 Skill 介绍。普通专辑转换为手册，旧技能章节保留兼容入口和权限。

离线回归、托管 Storage、真实模型与 Obsidian 原生操作分别记录结果。没有实现变化的流程可以明确引用已有版本证据；插件视图替身不计为原生宿主验收。

## 持续检查方法

运行现有内容、发布、后台、分身与配置测试，数据库使用独立 PostgreSQL / pgvector 验证并发和回滚。云端匿名反例由 `npm run test:security:smoke -- https://你的站点` 检查；该命令不发有效回调或写入业务数据。

依赖审查分别执行 `npm audit --omit=dev` 与完整审计。开发依赖例外必须记录受影响组件、使用范围和处理策略；生产依赖高危问题不能以开发工具例外放行。

生产与开发依赖按最终锁文件分别审计，结果与同一提交的 CI 一并记录；锁文件变化后重新核查。生成工具不参与应用运行时；保留的第三方样式、图标及插件依赖须附来源和许可证。

公开稿脱敏仍由站主负责；服务端不能保证站主主动发布的文字没有个人信息。服务端凭据和真实环境文件始终保持私有。
