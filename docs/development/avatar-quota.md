# AI 调用预算与期限

分身与后台页面生成使用共享生成连接及月度次数预算。知识库查询、构建与评测也可能计费，但不占生成次数；供应商账单预算另在供应商控制台管理。

## 计数与权威

`ai_calls` 私有账本记录请求 UUID、任务、连接版本、账户／IP、状态和用量；会话角色无表访问权或预算函数执行权。历史 `avatar_usage` 保留并计入月预算和本人今日统计，不通过删除或改低用量释放额度。

- 分身 UTC 日限额：注册 20、有效订阅 100、匿名同 IP 5；站主免分身日限额，但遵守站级月限额。
- 后台页面生成限站主，每日 60 次；与分身共用站主设置的月度上限。
- 查询向量每日匿名同 IP 15、登录账户 300；每种任务每账户／IP 每分钟最多 5 次。连接检查每日 20 次，不读取文章。
- 缓存命中先于查询向量与预算预留，不调用供应商。没有可注入证据时不生成，释放预留；已派发的查询向量仍计入检索频控。

`reserve_ai_call` 在 READ COMMITTED 下以短事务 advisory lock 原子检查并预留。同一请求 ID 只授权一次；客户端不能提交限额。`dispatch_ai_call` 仅一次将未过期预留改为 dispatched，重新检查配置与功能状态；只有明确收到成功才发出请求。派发响应丢失时不调用供应商，也不假定额度可回收。

| 状态 | 计入生成预算 | 后续动作 |
|---|---|---|
| reserved | 60 秒内计入 | 派发、释放或过期 |
| dispatched | 计入 | 成功或未知；不因租期过去释放 |
| succeeded | 计入 | 终态 |
| unknown | 计入 | 人工与供应商核对，不自动重试 |
| released | 不计入 | 终态 |

`avatar_usage_today()` 只按 `auth.uid()` 返回本人 UTC 当日新旧账本总量，不接受账户 ID；不能读取他人用量或私有连接。读取失败显示不可用，不显示虚假的剩余次数。

## 期限、取消与费用

分身路由总期限 45 秒，函数上限 60 秒；问答内部预算 35 秒，查询向量最多 10 秒，数据库单次 6 秒。页面生成总期限 45 秒。原生 HTTPS 出站固定受信目标、验证并绑定公网 DNS 地址、保留 TLS hostname、不跟随重定向；请求最多 128 KiB、响应最多 1 MiB。JSON 与 SSE 都验证完成状态；中断、工具结果及截断不能写成完整缓存。

索引和评测每请求最多一个外部批次，最多 16 项、供应商期限 15 秒、路由总期限 20 秒、租约 90 秒。过期或未知批次必须显式确认重复费用风险后手动重试；成功项不重复发送。关闭管理页面停止后续派发，不能保证供应商已停止处理正在运行的请求。

月限额通知每月去重、尽力发送，不具有权益邮件出箱的送达保证。日志仅固定错误代码和非敏感摘要，不记录 Key、文本或供应商原始错误。

## 验证

- `npm run test:ai`：私有配置、CAS、目标与密钥绑定、出站与三协议、完整覆盖、租约、来源失效、评测分组。
- `npm run test:avatar`：实际权限过滤、无证据不生成、预算先于查询、缓存权益失效、未知结果保守计费。
- `npm run test:admin`：站主网关、本人用量及部署状态。
- `npm run db:baseline:check`：新装／历史升级／最终状态重建等价，历史数据保留、默认权限收口。
- 真实 PostgreSQL 并发作业与真实部署网络的供应商验收分别执行，不能用本机离线替身替代。

升级前备份并关闭分身，应用全部缺失迁移后运行匹配的 `verify.sql`，再部署配套应用、检查连接和知识库。旧应用不应继续承接问答；回滚不能重新启用已退休的环境变量／旧向量路径。
