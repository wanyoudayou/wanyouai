# 发布和使用 Skill

Skill 由一篇公开介绍和一个私有文件包组成。访客先读介绍，登录并取得权限后下载；站主还可开启网页内的文本对话。包内脚本可供用户下载到自己的工具中使用，网站不会运行脚本。

## 1. 配置私有存储

在本网站对应的 Supabase 项目打开 **Storage → New bucket**，创建：

| 字段 | 填写值 |
|---|---|
| Bucket name | `skill-packages`，固定名称 |
| Public bucket | 关闭 |
| Restrict file size | 开启，20 MB；工具使用精确 20 MiB（20,971,520 字节） |
| Restrict MIME types | 开启，`application/zip` |

此桶与公开图片桶 `media`、图片暂存桶 `media-uploads` 分开。不要添加允许访客任意读取这个桶的 policy。数据库安装／升级已配置限制性访问策略；`verify.sql` 可检查策略是否存在，实际上传下载仍需下面的操作验证。

熟悉终端时，可在项目根目录完成 `npm ci`、填好 `.env.local` 中的 Supabase URL 与服务端密钥，再运行 `npm run storage:setup -- --skills` 只读检查，确认目标项目正确后运行 `npm run storage:setup -- --skills --apply` 创建或补齐限制。命令会显示目标项目与配置检查结果，不替你打开公开访问。参数详情见 [素材库命令说明](../contracts/media-library.md#可选使用命令工具配置桶)。不需要新增环境变量。

## 2. 准备包

文件夹名称使用小写英文及连字符，例如 `text-helper`：

```text
text-helper/
  SKILL.md
  references/style.md
  scripts/example.py
```

`SKILL.md` 示例：

```markdown
---
name: text-helper
description: 根据指定风格整理用户提供的文字。
---
先询问用户的读者、用途与篇幅，再阅读 references/style.md。
只改写用户提供的资料；缺少事实时明确询问，不补造数据。
```

参考资料和脚本可按需省略。不要放入真实 `.env`、API Key、私钥、私人笔记或不打算交付的文件。格式检查通过只表示文件可安全存储和读取，不代表脚本可信。

## 3. 发布

1. 后台 **内容管理 → SKILL → 新建 Skill 介绍**，写清用途、输入和交付内容。介绍全文公开；保存草稿后可继续编辑，确认发布后进入版本管理。
2. 上传 ZIP 或文件夹，填写版本号和更新说明。文件夹会显示包含与排除清单。等待“版本已保存”；出现超时先点“查询并确认本次上传”。
3. 选择当前交付版本，设置价格。`0` 表示登录后免费使用；收费 Skill 复用已配置的在线支付、订阅与权益。
4. 如需网页对话，先在 **AI 设置**配置并检查生成模型连接，再勾选“启用在线文本对话”，填写使用引导并保存。不必建立全站向量索引。
5. 打开前台介绍：登录后验证下载，检查版本与 SHA-256；未购账户不能下载收费包。点击右栏“切换成在线测试”，在当前页输入任务；手机先点击底部 SKILL 打开面板。切换模式不会调用模型，发送任务才会调用并消耗额度。输入草稿在本页模式切换和关闭抽屉后保留；刷新可恢复已提交的对话，尚未发送的文字需另行保存。

新版本上传后不会自动替换交付版本，需重新选择并保存。已有对话继续使用创建时的版本，新对话使用当前版本。核心 `SKILL.md` 超过 32 KiB 时可下载但不能开启在线对话；请精简指令，把补充资料放在 `references/`。

## 4. 下载与安装

在前台 Skill 页面点击下载，或生成安装说明，将其交给支持 Agent Skills 的本地工具。说明里的安装授权有效 15 分钟，仅用于指定版本；可在页面撤销。安装前核对版本、摘要与目录，遇到同名文件先确认；不要让工具自动运行未知脚本。

暂停 Skill 后不再出售，已有权益按内容保留规则继续使用；已下载文件不能远程撤回。后台“暂存文件维护”只清理过期未发布上传，不影响历史版本。

## 5. 对话中断后

出现未完成或结果未确认提示时，先点“查询本轮状态”。查询只读取已保存结果，不会重发问题。若仍未确认，保留输入和参考编号，由站主在 Vercel 项目的 Logs 中按编号查看错误码。不要把未知结果当作未计费，也不要连续重复发送；模型连接、额度或调用频率问题需按具体错误处理。
