# 用 OPC手册管理器上传手册草稿

OPC手册管理器适用于桌面版 Obsidian 1.14.4 或以上，管理当前 Vault 内的多份手册。插件只做**本地 → 线上草稿**的单向上传；手册详情、价格、阅读权限和公开发布统一在网站后台完成。网站需支持 `draft-upload-v2`，插件使用 1.4.1 或以上。

## 1. 安装与首次配置

1. 下载 [wanyou-handbooks.zip](../../releases/obsidian/wanyou-handbooks.zip) 和 [SHA-256 校验文件](../../releases/obsidian/wanyou-handbooks.zip.sha256)。下载源码包时，也可直接使用其中 `releases/obsidian/` 目录内的文件，无需编译。解压后将 `wanyou-handbooks` 文件夹放入 Vault 的 `.obsidian/plugins/`，文件夹内直接包含 `main.js`、`manifest.json`、`styles.css`。
2. 在 Obsidian **设置 → 第三方插件**中启用“OPC手册管理器”。升级时停用插件，替换安装包中的文件，保留原 `data.json`，再启用；已有本地列表、绑定和凭据可继续使用。需要自行构建时，在项目根目录执行 `npm ci`、`npm run plugin:build`，正式安装包写入 `releases/obsidian/`。
3. 网站后台打开 **内容管理 → Obsidian 连接**，创建命名凭据，复制仅显示一次的 `whp_…` 值。
4. 在 Obsidian 的 **OPC手册管理器**设置中填写网站固定 HTTPS 地址及该凭据，点击“保存凭据并连接”。凭据保存在 Obsidian 密钥库，普通配置只保存引用；保存后不回显，留空保留原凭据。

之后打开插件、重启 Obsidian 或从网站返回插件时，会自动恢复连接并静默读取线上状态，无需每次点击连接。读取失败时保留本地列表并显示原因，可点击“刷新线上状态”重试；未成功读取的状态不会显示为最新。更换网站地址后，需要保存该站点自己的凭据。

专用凭据只允许管理本站手册草稿及必要图片，不使用站主密码、`PUBLISH_TOKEN` 或 Supabase 密钥。不再使用的设备可在网站后台撤销连接。

## 2. 载入本地文件夹

点击“批量载入文件夹”，勾选当前 Vault 内的一个或多个目录。载入只记录本机路径，不创建线上内容；每份手册只读取本目录根部 Markdown，父子目录可分别管理，不会重复上传子目录文稿。

```text
我的手册/
  README.md
  第一章.md
  第二章.md
  进阶/内部笔记.md  # 忽略，不上传
附件/
  流程图.png
```

- 根目录 `README.md` 是手册介绍，文件名不区分大小写，只能有一份。缺少时可勾选“创建空白 README.md”，插件不会覆盖已有文件。README 发布后全文公开。
- 子目录笔记、未引用图片和其他文件直接忽略，不作为上传障碍。
- 新文稿未指定 slug 时，README 使用“专辑标识-readme”，其他章节自动生成稳定唯一地址；后续同步保持原地址。
- 支持标准 Markdown 图片和 Obsidian `![[流程图.png]]`。只读取所选文稿实际引用的 Vault 内图片，不上传整个附件目录。
- 普通笔记链接不自动上传目标笔记；`![[另一篇笔记]]` 会提示具体位置，请改为正文或普通链接。
- 图片上传到公开素材库，持有图片 URL 的人可以读取。付费正文不使图片获得额外访问保护。
- 类型、阅读权限、价格和发布时间在网页后台管理。本地 `type`、`access`、`price`、`series_slug`、`published_at` 属性会在比对时列为已忽略，不改变网站设置；新草稿默认按登录可读准备，已保存的草稿和已发布文章保留网站当前权限。

## 3. 首次上传与网页设置

1. 展开本地手册，点击“上传为新手册草稿／关联手册”。新建时填写名称和网址标识，也可关联现有手册；这里不设置权限、价格或发布状态。
2. 点击“确认目标并比对”，查看左右列表：左侧是本地文稿，右侧是线上文稿及状态。展开“查看正文比对”可对照正文。
3. 核对文稿与公开图片，勾选确认，再点击“确认上传草稿”。进度显示：图片 → 文稿草稿 → 线上状态。上传成功不会自动公开正文或手册。
4. 点击同一条目内的“打开网页手册设置”。在网站后台配置手册详情、价格和导航；在“待发布更新”查看整辑清单、阅读权限和预览。需要修改的文稿先点“编辑”，完成后刷新清单。
5. 新手册选择公开 README，按需要勾选“发布成功后同时上架专辑”；核对范围后确认发布全部或选中的章节。若其中有错误或版本冲突，本批不会部分上线。

插件返回本页后会读取网站的最新状态。手册状态、已发布版本与待处理草稿分别显示，文稿修订号不是整份手册的统一版本号。

## 4. 更新、覆盖与保留

本地修改文稿或引用图片后，点击“比对本地与线上”。

全部文稿相同时，插件提示“无需上传”，不再要求确认上传。线上仍有草稿时，可直接打开网页后台审核发布；全部已发布时，可继续本地编辑。

| 比对结果 | 操作 |
|---|---|
| 本地新增 | 新增线上草稿 |
| 内容相同 | 跳过，不重复创建修订 |
| 本地与线上不同 | 左右核对后，逐项勾选“用本地覆盖线上草稿”；保留历史，创建新的待发布修订 |
| 仅在线上 | 保留，不删除 |
| 比对后网站又有修改 | 停止该项，重新比对并确认，不覆盖未经查看的新版本 |
| 本地文件改名或删除 | 线上原文稿保留；不会推断删除或自动替换另一篇文章 |

覆盖只更新草稿，当前公开正文保持原样，仍须在网页后台发布。插件不会把网站正文写回 Vault，也不提供线上文稿删除操作。“移出本地列表”只取消本机管理和绑定，保留两端文件。

## 5. 失败恢复

进度和错误留在对应手册的展开区。部分成功时，先查看未完成文稿的原因，再重新比对并确认上传；已成功且相同的草稿会跳过。

响应中断后，插件先尝试按原任务编号只读查询，不自动重发。恢复连接后也可点击“查询未确认任务”；查询没有完成记录不代表服务器已停止处理。手动继续时沿用原任务编号，避免重复提交。

若提示图片上传凭据过期，重新比对并确认，由插件申请新凭据；若提示线上版本改变，重新查看差异。线上手册已删除或归档时，可以解除无效的本机绑定后重新选择目标，本地文件保留。
