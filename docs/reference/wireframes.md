# 页面骨架

布局尺寸与色彩见[设计令牌](design-tokens.md)，具体页面行为见[页面契约](pages.md)。

## 桌面（≥1280px）

```text
导航 236px │ 内容区：Hero / 列表 / 阅读 │ 可选右栏 300px
站点身份   │ 标题、摘要、状态和动作    │ 分身 / 本页目录
固定栏目   │ 正文或内容卡片            │ 按页面需要显示
自定义入口 │                          │
主题与账户 │                          │
```

阅读页左栏可切章节树，中列保持阅读宽度。购买动作位于正文付费墙或方案组件；图片不因主题反色。

## 平板（768–1279px）

```text
图标栏 │ 主内容
目录钮 │ 完整目录与分身按需展开
```

## 手机（<768px）

```text
主内容：标题 / 卡片 / 阅读 / 表单
安全区与底部操作留白
首页 │ 目录 │ 分身 │ 我的
```

目录与分身互斥，抽屉打开后保持焦点，关闭返回触发点。未启用分身时其他入口均分。后台使用自己的菜单抽屉。

## 后台

```text
分组左栏   │ 标题、说明、创建入口
概览       │ 搜索 / 状态 / 类型 / 排序 / 页大小
内容       │ 当前页记录：名称、状态、时间、操作
业务       │ 筛选总数 / 页码 / 前后页
设置       │
维护       │ 短操作或预览按需打开右侧快捷栏
```

文章、专辑、独立页、收款订单分别有明确路由。列表打开编辑页后保留返回位置；章节与版本分别按所属对象分页。普通专辑复用阅读页，不显示活动和技能扩展字段。
