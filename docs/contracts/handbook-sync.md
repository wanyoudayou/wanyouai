# 手册同步协议 v1

Obsidian 管理器只做本地文稿到线上草稿的单向上传。网页后台负责详情、阅读权限、定价与发布。插件安装及操作见 [Obsidian 手册上传](../deployment/obsidian.md)。

## 身份与边界

站主在 `/admin/handbooks/connect` 创建命名凭据，明文只显示一次；服务器仅存 SHA-256，最多 10 个活跃凭据，可分别撤销。每次请求验证凭据及站主身份，每个目标继续校验未归档且 `series.type=handbook`。该凭据不被后台通用接口、其他发布 API 或 Supabase 接受，不能管理活动、Skill、交易、用户、AI 或导出。

插件允许创建手册草稿、读取状态、比对与上传文稿，以及上传实际引用图片；不调用发布、上架或删除。服务端同步接口也拒绝 `publish`、`activate`。内部历史 RPC 仍供受信维护与兼容回放使用，不对客户端开放。

连接绑定 HTTPS Origin，拒绝重定向；更换站点需重新保存凭据。SecretStorage 保存令牌，普通配置只保存引用、绑定、摘要和任务编号。并发连接合并为一次后台握手，同一保存配置在当前插件会话内复用连接；每个 API 请求仍重新鉴权。配置改变会丢弃旧连接结果，失败不无限重试。SecretStorage 不是其他恶意本地插件的隔离沙箱。

## 接口

统一前缀 `/api/handbooks/v1/`，请求头 `Authorization: Bearer whp_…`，响应禁缓存，JSON 请求最多 2 MiB。每凭据每分钟最多 180 个请求。

| 操作 | 内容 |
|---|---|
| GET `connect` | 协议版本、手册范围、受信上传 Origin、公开 anon/publishable key、`draft-upload-v2` 能力标识 |
| GET `list` | 手册状态，更新时间及 ID 稳定分页，100 项/页 |
| GET `inventory` | 指定手册的文件修订、图片引用及全部线上文章元数据；各组分别分页后合并，不取正文；网页创建的文章也可见 |
| GET `status` | 仅当前凭据的原操作结果 |
| POST `create` | 创建草稿手册 |
| POST `compare` | 冻结稿件比对：摘要、预期修订、线上时间戳、正文差异及差异来源 |
| POST `stage` | 根据已核对摘要、预期修订和线上时间戳保存新草稿；内容有差异须显式 `overwriteOnline=true` |
| POST `rename` | 受控更新文件绑定路径，不删除文章；管理器不自动推断改名 |
| POST `media-prepare` / `media-finish` | 当前凭据与手册的图片上传及 CAS 绑定 |

写操作携带 UUID `operationId`。同 ID 同内容返回原结果，同 ID 不同内容拒绝。事务内重新验证凭据、目标、文件修订及文章时间戳；图片、读取与网络调用在事务外完成。

## 草稿与覆盖

所有同步请求在服务端按草稿上传处理，不由客户端选择发布模式。权限由现有文章、已存草稿及保守的新草稿默认值依次确定；本地 access 不改变现有权限，新章节按登录可读准备，README 按公开介绍准备。插件在解析笔记时忽略由网站管理的 type、access、price、series_slug、published_at 属性，并列出被忽略的字段；其他格式错误指出文件名。任何正文公开仍需站主到网页后台确认。

左右列表展示本地文稿与线上最新状态。已有文稿的内容不同，需逐项明确确认以本地版本更新线上草稿；保留历史修订，不删除文章，不直接替换当前公开正文。若比对后线上时间戳或修订再次改变，拒绝该项并要求重新比对；强制覆盖不能绕过这道检查。

状态投影区分手册生命周期、文章当前状态、实际已发布版本与待发布修订。首次进入、切回插件及手动刷新会读取线上状态；读取失败保留本地资料和旧读取时间，不伪装为同步完成。正文差异仅在已授权的比对响应中返回，列表接口不携带正文。

## 本地与恢复

根目录 README 文件名不区分大小写，重复变体阻断；缺少时经勾选创建空白文件，不覆盖，创建与读取都检查 Vault 边界。只读选定文件夹根目录的 Markdown 和实际引用图片；子目录文稿和无关文件在解析前排除，不展开笔记嵌入，不上传隐藏配置或整个共享附件目录。最多 1000 篇 / 50 MiB 文字，500 张 / 50 MiB 图片，单图 10 MiB；图片始终公开。

进度、错误、比对与下一步操作位于对应手册展开区，进度更新不重建整页。部分完成真实保留已上传项；重新比对后跳过相同内容，不重复增加修订。网络未知先按原任务编号只读查询，不自动重发；没有完成记录不代表任务已经停止。手动继续沿用原编号。只有明确 `UPLOAD_EXPIRED` 才重新申请图片凭据。

本地删除不删除线上文稿；仅在线上的文件和网页创建的文章保留。本地移出列表只解除本机管理。插件不把线上正文写回 Vault，不自动改名或跨文稿绑定。版本升级保留现有绑定和凭据。

插件状态以最新线上元数据为准：全部草稿已在网页发布时显示已同步线上发布；存在新本地变化时提示比对。正文和权限继续由网页后台全辑审核，插件不新增发布能力。
