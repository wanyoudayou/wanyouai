# 发布与回归验收矩阵

## 部署检查与配置指引

人机校验由 `/admin/security` 管理。`tests/admin-turnstile.test.ts` 覆盖站主专用保存、配置与密钥同事务、并发版本冲突、换 Site Key 须换配套密钥、停用覆盖旧变量、公开配置无 Secret Key、固定 hostname／action 校验及上游失败关闭。真实挑战仍须在固定站点域名人工完成；不能以合成响应替代。

| 场景 | 必须满足 |
|---|---|
| 匿名或普通账户访问部署诊断 | 在读取环境、创建权威客户端或探测远端前拒绝 |
| 登录 SMTP 可用，应用事务邮件变量缺失 | 不推断为事务邮件已启用；区分两条邮件链路，部分缺失时指出变量名，绝不输出值 |
| 自动条件全部通过 | 实际登录、支付、邮件送达、分身权限与基础部署仍需人工验收，不自动标为成功 |
| 可选业务关闭／配置读取失败 | 关闭的业务验收显示未启用；读取失败不冒充关闭或通过；已有邮件积压仍需显示 |
| 人工验收说明 | 按邮件、支付、AI、基础站点列出步骤及预期，键盘可展开；不持久保存结论，不触发收费、发信或生成 |
| 环境模板与示例指南 | 模板仅保留用途、Type 与入口；部署指南给出参数获取、填写位置与生效步骤；OTP 位数在 Email OTP length 建议设为 6 |

自动化入口：`tests/admin-deployment.test.ts`；真实部署按[部署指南](../deployment/guide.md#67-人工确认如何完成实际部署验收)逐项核对。

## 图片素材库

| 场景 | 必须满足 |
|---|---|
| 匿名、普通登录账户读素材目录／写入文件元数据 | 拒绝；上传记录与签名接口仅同源站主使用 |
| 大于 4.5 MB、至 10 MiB 的有效图片 | 浏览器直传私有暂存桶；校验完成后才能选用，不经过应用上传请求体 |
| 类型伪造、损坏图片、错误摘要／大小、活动 SVG | 拒绝或安全转 PNG，不把未校验原文件写入公开桶 |
| 重复上传、确认响应丢失后重试 | 复用不可变对象及素材记录；不重复发布内容，不改变历史输入摘要 |
| 图片跨文章／专辑复用 | 目录元数据和真实字节均验证；未登记、元数据不符或字节篡改拒绝 |
| 图片归档、改名、替代文字更新 | 已有页面及历史版本继续可用；新选图隐藏归档项，可恢复 |
| 搜索特殊字符、分页、列表读取失败 | 字面匹配；20/50/100、唯一标识排序；失败不伪装零条 |
| 选图窗口关闭、主题切换、上传失败 | 焦点返回，编辑草稿保留；窄屏无横向溢出 |
| 旧图片登记、暂存维护 | 保留旧地址与字节；只清理过期私有暂存，不删除公开文件 |

自动化入口：`tests/admin-media-library.test.ts`、`tests/browser/media-library.spec.ts`、Storage 配置测试与真实 PostgreSQL 并发作业。云端直传及对象权限须另在测试部署验收。

## 履约权威入口

`tests/admin-bookings.test.ts` 加载完整最终 SQL 链并验证：

| 场景 | 必须满足 |
|---|---|
| 报价 → 客户接受 → 条款草稿 / 发送 → 客户确认 → 开工 | 按序成功；跳步及其他用户确认被拒 |
| 条款未确认时启动检查点 | 被拒 |
| owner 通过 RPC 或直接 UPDATE 完成整单验收 | RPC 返回拒绝；直接写表 permission denied |
| 客户节点反馈、驳回、重新交付、验收 | 每次交互追加历史，重放验收被拒 |
| 订单客户整单验收 → owner 结案 | 成功；无关用户验收被拒 |
| settled / declined 后修改订单或检查点 | 两个会话 RPC 均拒绝，页面只读 |
| owner / 客户直接写 bookings / milestones | 被拒；保留有权限的读取 |

此自动化基于 PGlite 模拟 Auth schema；实际 REST、Auth 与并发验收另在托管测试项目验证。

> 前提：独立测试项目执行当前 install → verify；权限夹具仅在测试环境运行，不使用生产用户/订单。当前版本与证据见[发布状态](../development/release-status.md)。以下是验收条件，不是当前执行结果。

## 1. 阅读权限矩阵

`1` 表示可读取 `article_bodies`，`0` 表示不可读取。

| 内容 | 匿名 | 注册 | 订阅 | 专辑购买者 | 单篇购买者 | 活动票持有人 |
|---|---:|---:|---:|---:|---:|---:|
| public 博客 | 1 | 1 | 1 | 1 | 1 | 1 |
| registered 博客 | 0 | 1 | 1 | 1 | 1 | 1 |
| subscriber 博客 | 0 | 0 | 1 | 0 | 0 | 0 |
| paid 单篇 | 0 | 0 | 1 | 0 | 1 | 0 |
| paid 手册章节 | 0 | 0 | 1 | 1 | 0 | 0 |
| 活动 README | 1 | 1 | 1 | 1 | 1 | 1 |
| 活动 subscriber 沉淀 | 0 | 0 | 1 | 0 | 0 | 1 |
| archived 内容 | 0 | 0 | 0 | 0 | 0 | 0 |

补充不变量：

- README 须属于同专辑，按产品公开例外放行；机器目录额外要求公开 access，不能让跨专辑指针扩大授权。
- `paused` 停售不停读：已授权者仍读全文，购买入口消失。
- 权益是并集，不是等级覆盖。
- 订阅到期即失去订阅带来的阅读权限（`ends_at` 等于当前时间也无效），不依赖定时任务；永久专辑与永久单篇权益继续有效。
- 订单内容入口仅生成有效站内路径，单篇/四类专辑路由正确；草稿、归档、错误类型或不可读取的目标不生成链接，目标页的权限判断保持独立。

## 3. RLS SQL 验收

按 `rls-fixtures.sql` 的注释分别切换身份。

| 场景 | 断言 |
|---|---|
| 匿名查 paid 单篇 body | count = 0 |
| 注册用户查 registered body | count = 1 |
| 订阅用户查 subscriber body | count = 1 |
| 专辑购买者查该专辑章节 | count = 1 |
| 专辑购买者查无关单篇 | count = 0 |
| 单篇购买者查该单篇 | count = 1 |
| 单篇购买者查无关专辑 | count = 0 |
| 活动票持有人查该活动沉淀 | count = 1 |
| 非 owner UPDATE `site_config` | 拒绝 |
| 非 owner INSERT `services` | 拒绝 |
| 非 owner INSERT `orders` | 拒绝（订单仅支付服务端函数创建） |
| 非 owner INSERT / UPDATE `payment_events` | 拒绝（回调仅服务端写入） |
| anon / authenticated 调用 `claim_pending_payment_reconciliation()` | 拒绝；service_role 可认领，创建未满 10 分钟与 30 分钟内已认领单不返回；已付单永不返回 |
| 已验证且匹配 `OWNER_EMAIL` 的首位用户，经服务端 `claim_owner_for()` | true |
| 另一用户经服务端 `claim_owner_for()` | false；`authenticated` 直接调用被拒 |
| Publishable / Legacy anon 公钥误填 `SUPABASE_SERVICE_ROLE_KEY` | 配置预检报错；服务端拒绝创建管理客户端，不尝试认领 |
| OTP / 邮件链接验证成功，随后站主认领请求失败 | 登录后的页面保留站主验证失败提示，不误报邮箱不匹配；日志不含邮箱、密钥或 RPC 原始错误正文 |

`rls-fixtures.sql` 已内置 first / second claim 断言；其余查询保留为手动验收步骤，避免测试脚本自行切换 JWT 导致歧义。

## 6. 站主部署与内容闭环

1. 全新部署进入 `/admin`；
2. OWNER_EMAIL 指定邮箱通过验证码或邮件链接登录；
3. 已验证的指定邮箱经服务端 `claim_owner_for()` 返回 true；
4. 修改站名、Hero 问句、名片与约束；
5. 前台首页、`/card`、`/card.json` 同步；
6. 第二个邮箱登录后无法 claim owner；
7. 浏览器上传含图与 paywall 的 Markdown；
8. 预览显示匿名截断与图片；
9. 移动切点后重新提交生成新版本；
10. 发布后前台、`/llms.txt`、版本记录一致；
11. 建立已定价服务并发布，`card.json` 输出该服务；
12. 建立活动字段并流转 `upcoming → registering`，前台活动字段同步。

## 8. 支付、邮件与调度

| 场景 | 条件 |
|---|---|
| 建单与定价 | 客户端不能指定金额；SKU、资格、价格快照由服务端/数据库校验；跨用户订单拒绝 |
| 商户订单号 | 新单唯一 32 位数字，与内部 id 分离；克隆库不得同时接入来源商户结算 |
| 回调与查单 | 签名、商户、金额、交易状态和关联核验；重复流水不新增事件/权益/邮件 |
| 无通知、无返回 | 查单调度认领符合条件的 pending，在受控供应商响应下完成唯一结算；区分受控测试与真实平台交易 |
| 并发与故障 | 独立连接争建单/结算、超时/锁等待、事务回滚、worker 租约过期和旧 token 确认均符合契约 |
| 邮件 | 权益与 outbox 同事务；实际非空任务 sent/供应商收据/收件核对；失败不撤销权益，终止任务人工处理 |
| 调度 | 鉴权、TLS、超时和健康摘要；至少连续两次成功调用；空队列不证明真实送达 |

## 9. 分身、会话与活动

- 四身份逐项检查检索后的代码验权，prompt/缓存/流式输出无未授权正文；撤权、归档与公开稿变化使缓存失配。
- 原始会话仅当事人与站主读取；公开表单首次为空，明确编辑和确认后发布；撤回保留私有记录，关联内容不可见时公开稿也不可读。
- UTC 日/月原子配额、争最后名额、重复派发、过期/跨日拒绝、unknown 保留计数；45 秒路由/20 秒生成期限，取消和断流不当成功，不自动重试。
- 服务报价→客户接受→八项条款确认→开工→检查点→交付→客户验收→结案→评价；越权、跳步、直接写表与终态写入拒绝。
- 活动收费/免费/会员资格分别报名，站主二维码/名单核销幂等；核销与 event 权益同事务，非当事人无 PII；纪要按订阅或活动票解锁。

## 10. 导出、恢复与文件治理

- owner 导出完整 Markdown/CSV/页面/配置与白名单 JSON，读取失败拒绝部分包；清单、CRC、大小和 SHA-256 匹配；能用标准工具阅读编辑和统计。
- ZIP 不含密钥/密码/令牌/Storage 字节，不宣称整站恢复或任意托管容量；恢复另按[运维手册](../operations/backup-and-restore.md)。
- 新装和升级目录等价，旧行摘要保留；restore-hardening 后完整 ACL 与 RLS 核对，不只比授权数量。
- 当前文档链接、脚本入口、SQL 清单/生成摘要无漂移；运行和测试不依赖本地归档，源码包不含真实 env、机器状态或过程日志。

## 手册、后台与默认内容

- 手册：匿名/注册/订阅/已购/站主复核阅读与价格权威；暂停可读不售，归档不可读；机器输出不泄露受限正文。
- 逻辑文档：纯待审核、正式+待审核、无导入记录均可定位；超过旧上限、同时间排序、分页边界、中文及字面特殊字符、读取失败不伪装为零。
- 初始化：空站、重试、中断继续、网址冲突、已有修改；全部章节成功前不激活默认导航；既有实例只主动载入。
- 视觉：浅/深、系统切换与持久化、1440/1100/390/320px、键盘与抽屉互斥、编辑保留、无新增 hydration 错误；完整真实部署另行验收。
- 升级：追加迁移、新装等价、旧数据保留；应用回滚版本必须兼容独立 Skill、手册映射与新发布事务。

## 横幅配置与主题

浅深横幅独立保存与展示，任一留空只回退到本主题内置背景。旧单张图片仅作为浅色兼容值；下一次保存写入双主题字段，不继续保存旧文字明暗设置。主题切换不清空编辑或提问输入，首次系统深色在 JavaScript 执行前也使用深色背景。

新装不预置头像和 Logo，留空使用名称首字标。旧模板的本地图片路径按未配置处理，其他自有图片地址保持原值。分享元数据无封面时提供文字摘要，有合法公开封面时输出图片地址；不引用已移除的模板资产。浏览器确认两套内置背景及自定义图片实际加载成功。

## 统一 AI 与知识库

| 场景 | 必须满足 |
|---|---|
| 匿名／普通账户访问 AI 设置、连接检查或索引管理 | 服务端先验站主再读取配置；所有写入口同源校验；不返回 Key |
| 保存并发、第二连接失败、切换供应商、显式复用 | 同事务全部成功或回滚；CAS 拒绝覆盖；新目标须有对应 Key；旧索引绑定原连接 |
| 非公网 DNS、混合 A/AAAA、重定向、无结束帧、截断 | 派发前拒绝不安全出站；绑定已检查 IP 与原 TLS hostname；完整响应有界验证，不自动重试 |
| 超过 64 片、中文／emoji／长代码、末尾信息 | 分片按 Unicode 码点完整连续覆盖；每片至 2048 UTF-8 字节，不截取前缀 |
| 两个 worker、租约超时、写回丢失、修订中途更新 | 批次互斥；未知结果停止并手动确认后重试；旧来源回写废弃，旧向量不参与检索 |
| 新索引切换与相关性 | 站主明确确认后原子切换；无报告、低命中和库外返回均不阻断启用；完整覆盖、来源版本、已验证连接仍强制；旧代际不混用新模型 |
| 错配高亮与来源采纳 | 错配以警示底色／图标／文字显示；逐项采纳仅追加到草稿且不重复，每题最多 3 个来源；原问题、来源、结果及得分保留；可单独撤销，取消恢复原报告；草稿存在时不启用旧报告；改题后禁用旧来源采纳；库外题转有答案重新校验题数，重新检查须另行确认费用 |
| 索引五步流程与恢复 | 初次、同步、重建含义清楚；全部向量就绪且来源一致时直接进入确认启用；读取失败不能解锁；刷新不发起模型调用，已确认批次不重放 |
| 增量候选与已有活动索引 | 只复用同连接、同处理规则、当前来源摘要及完整片段一致的已确认向量；失效／失败／未知结果不复制；候选复用已接受问题和阈值做新回归，不复用旧成绩，切换前活动索引不被写入 |
| 连接与验收交互 | 当前步骤唯一展开；连接检查就地反馈；编辑、确认发送、运行、结果互斥；示例明确可跳过且只导入问题；许可随修改失效；自动题未核对不能运行，1–100 题无配比，诊断不修改运行阈值，取消编辑确认放弃；单题回答默认匿名且另行确认 |
| 失败结果与防误点 | 只读恢复上次查看的记录（单份自动显示，多份不猜测先后）、失败题目优先；直接定位修改并保留原结果；未改问题禁止重发；无阈值时只称候选来源；返回编辑不发送请求；草稿替换明确数量和范围 |
| 关闭分身、空库、库外问题、仅未购正文 | 前台隐藏未就绪入口；无可注入证据不调用生成，不退回通用聊天 |
| 匿名、注册、订阅、已购、站主与公开稿 | 再验生命周期与当前权益；未授权正文不入 prompt；私人会话不索引；只有明确公开副本可用 |
| 缓存、订阅过期、配置或正文变化 | 账户、有效权益、配置、代际与来源版本隔离；缓存命中先于预算和查询向量 |
| 页面生成、用量统计、导出 | 页面生成使用独立固定提示词，分身关闭仍可用；本人统计不读他人账本，站主概览合并新旧账本且不向用户开放明细；导出不包含 AI 凭据和索引私有表 |

| 站主确认时效 | 确认绑定代际、当前来源版本与连接；内容／连接变化后失效；旧报告或旧启用接口不能绕过当前确认 |
| 诊断与索引隔离 | 改题、采纳或查看报告不写向量和运行阈值；保留原报告；有效失败题应通过修改内容或检索实现后对比 |

自动化：`test:ai`、`test:avatar`、`test:admin`、数据库等价及真实 PostgreSQL 并发；真实模型兼容、索引相关性与匿名挑战在实际部署上单独验收。

## Skill 与手册插件

| 检查 | 必须满足 |
|---|---|
| 包格式 | Traversal、绝对路径、链接、加密、重名、伪摘要、CRC 损坏、超限实际解压及 YAML 复杂度拒收；脚本只下载 |
| 私有交付 | 匿名、未购、到期、撤销均无文件；免费登录、直接购买、有效订阅、站主允许；宽泛 Storage policy 不能开放私有包 |
| 交易兼容 | 新 Skill 价格快照、重复结算只开一次权益／入一次邮件箱；旧订单迟到回调保留原目标和金额 |
| 文本执行 | 跨包、任意 URL、Shell 等请求由代码拒绝；3 次生成／6 次读取／45 秒／128 KiB；每次调用计费，无未知结果自动重试 |
| 多轮隐私 | 用户与包版本由服务端绑定；客户端伪造历史拒绝；失去权益不返回旧上下文，不进入公开问答或共享缓存 |
| 插件范围 | 凭据撤销、跨类型对象、不同内容复用操作 ID 拒绝；请求不跟随跨站重定向；打包不含服务端模块 |
| 同步恢复 | 共享图片、中文路径、README 大小写、经勾选创建空白且不覆盖、重复 README 阻断、图片独立更新、改名、部分成功及断网；原任务只读查询不重发，进度和操作留在对应条目；无关笔记不读、不上传，本地删除不删线上 |
| 并发 | 网站与插件同时更新只允许一个基线提交；同内容不增版本；未完成首次手册保持草稿 |
| 草稿上传边界 | 所有上传／同步只保存草稿；客户端与同步 API 均不发布、上架或删除。服务端保留已有权限，不接受本地 access 修改；成功提供网页手册设置入口 |
| 左右比对与覆盖 | 线上已有差异须逐项确认才能另存草稿；仅在线上的绑定文稿与网页文章都保留；比对后修订或时间戳改变则拒绝，强制覆盖不绕过版本锁 |
| 静默状态 | 并发握手合并、同一配置复用、换站丢弃旧响应；进入与返回插件读取线上手册／文章状态和版本，失败保留旧数据与时间；草稿和已发布版本分别显示 |
| 升级 | 普通专辑 ID 保留，旧技能正文／章节／权益不丢失、不公开受限正文；新装与升级结构权限等价 |

自动化入口：`npm run test:skills`、`npm run test:handbooks`、`npm run plugin:build`、`npm run test:db:concurrency`、`npm run test:browser`。真实 Storage 签名上传／下载、真实 Obsidian 安装和经授权的模型调用另在测试站确认。离线替身不能替代托管服务或模型行为。

Skill 编辑与手册管理器交互：固定类型和公开权限有禁用样式及解释；下载右栏／手机抽屉、同页在线与本机切换、安装提示词复制通过浏览器检查。切换不导航、不派发模型请求；介绍正文、输入和会话保持，刷新可恢复本人会话；中断后只读查询且不自动重发，模型图片不自动加载。插件验证多文件夹列表、静默连接、左右比对、覆盖确认、仅草稿上传、线上状态、网页设置链接，以及三步进度和同操作 ID 恢复；原生 Vault 交互另作人工验收。

专辑整批发布须验证：非站主及插件凭据拒绝；跨专辑、旧修订、线上新修改与同请求变更范围拒绝；后一篇失败时前一篇及幂等记录一起回滚；成功重放无新增版本；新手册公开 README 与上架同事务；付费正文在多个标记时仍仅暴露首段预览。根目录导入忽略子目录异常文件，Obsidian 仍解析 Vault 共享图片；缺图片网页草稿可编辑，发布前继续完整校验。
