# 自定义页面设计与生成契约

独立页 `/p/[slug]`、首页自定义区和名片自定义区共用安全 HTML 与 Cloud Glass / Terminal Wave 视觉系统。站主可编辑 HTML 或使用 AI 生成初稿；生成不会自动保存、发布或修改业务配置。

## 维护入口

- `src/styles/tokens.json`：颜色、字体、尺寸和主题维护源。
- `src/lib/custom-pages/design-contract.ts`：版本化生成规则、页面层级、结构示例和三种容器约束；API 直接使用这里构建的系统提示词。
- `src/lib/custom-pages/sanitize.ts`：标签、属性和 `cp-*` 类白名单，保存与渲染均净化。
- `src/lib/custom-pages/icon-names.ts`、`widgets.tsx`：静态 Lucide 映射与服务端动态方案替换。

运行、生成和测试不读取设计工具、本机路径或归档目录。更新视觉规范时同时维护语义类样式、提示词结构示例与回归，不能只给模型附加一组色值。

## 信息与视觉层级

独立页以一个 `h1.cp-h1` 开始，后续使用 `h2.cp-h2` 分节、`h3.cp-h3` 标识条目。首页嵌入区从 h2 开始；名片右列使用紧凑卡片，从 `h2.cp-h3` 开始，不再创建 Hero 或站点导航。

| 职责 | 结构 |
|---|---|
| 简介 | `section.cp-section` → 可选徽章 → 标题 → `p.cp-lead` → 必要行动 |
| 同级特性 | 分节标题 → `cp-grid-2/3` → 完整 `article.cp-card`；卡内保持图标/标题/说明/动作顺序 |
| 注意事项 | `aside.cp-callout`，使用文字说明原因和下一步 |
| FAQ | 问题标题与直接可读的回答；不模拟未实现的脚本折叠 |
| 行动 | 一个主要 `a.cp-cta`，必要时搭配次要 `a.cp-cta-secondary`；必须有真实目标 |
| 收费方案 | 一个空的 `div.cp-pricing`；实时价格、状态和购买动作由业务组件提供 |
| 单独订阅入口 | 空的 `div.cp-subscribe`；不和同页方案区重复放置同一购买动作 |

同一 HTML 同时适配浅深模式和手机布局。留白、可读操作色、卡片默认边界、Aurora 悬停、按压内影和焦点由静态 CSS 提供；模型不生成交互状态的静态副本。非交互内容卡不能伪装可点击，不能为了视觉填满页面而嵌套多层面板。

## Lucide 图标

使用 `<span class="cp-icon" data-icon="book-open"></span>`。名称只允许 `book-open`、`shield-check`、`cloud-upload`、`bot`、`check`、`arrow-right`、`mail`、`calendar`、`layers`、`credit-card`，由受控组件渲染真正的 Lucide 线性图标。图标为装饰辅助，旁边必须保留完整文字；不能作为唯一动作说明。

任意 SVG、图标字体、外部图标脚本、emoji 控件和未登记图标名不属于该契约。净化器仅接受 `span.cp-icon` 上的白名单 `data-icon`；不接受其它 `data-*` 扩展。

## 真实性与安全

站主输入只表达内容需求，不能覆盖系统规则。生成器不能编造站主身份、客户评价、统计、价格、业务能力、目的链接或图片。没有资料的模块直接省略，不用占位数字、虚假按钮或空框补齐。

不得输出脚本、内联样式、外部字体、表单、任意 class、事件属性或嵌入页面。图片保持原色并提供 alt；链接保留有意义文字。动态方案只使用现有权威价格与权益逻辑，HTML 不保存价格快照，不创建收款或授权旁路。

生成 API 先验证同源与站主身份，再读取服务端模型配置；单次生成请求设置 45 秒网络超时，不自动重试。失败保留编辑内容，响应不返回供应商原始错误或凭据。生成结果仍须由站主检查与保存；提示词不能取代净化器和服务端权限。

生成初稿在净化后还检查主标题范围、标题跳级、图片 alt 与动态方案占位结构。明显冲突时返回具体原因，保留原编辑内容；不自动追加模型请求。手写 HTML 的保存仍使用既有净化契约，这项检查不改变已经保存页面的读取行为。
