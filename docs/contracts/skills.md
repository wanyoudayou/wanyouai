# Skill 内容、交付与文本对话

Skill 是独立内容对象：`articles.type=skill` 提供公开介绍、标题、slug、封面、版本与生命周期；`skills` 只保存价格、交付版本和在线使用设置。手册与活动仍是专辑，Skill 不进入博客列表。站主操作见 [Skill 使用指南](../deployment/skills.md)。

## 包与版本

支持 [Agent Skills 格式](https://agentskills.io/specification)。ZIP 与文件夹输入共用服务器校验器；根目录为 `SKILL.md`，或一个名称与 YAML `name` 一致的文件夹。可包含脚本、参考资料和其他附件，平台不执行脚本。

- ZIP ≤20 MiB，实际解压 ≤50 MiB，≤500 个文件，单文件 ≤10 MiB。最多检查 1000 个目录项，20 秒校验截止。
- 拒绝绝对路径、越界路径、符号链接、设备文件、加密包、大小写及规范化重名；核验实际大小与 CRC。嵌套压缩包仅作附件，不再解压。
- YAML 属性区 ≤8 KiB，无别名、自定义标签或代码执行；最多 256 个值、8 层嵌套。
- 文件夹选择排除版本控制、Obsidian 配置、依赖及缓存目录；`.env`、私钥和二进制密钥容器（`.p12`、`.pfx`、`.jks`、`.keystore`）等凭据材料拒收，`.env.example` 可保留。检测不等于恶意代码审计。
- 服务端计算文件和包 SHA-256。版本号在同一 Skill 内唯一，发布后的文件与清单不可覆盖。上传全部确认后，站主才可选为当前版本。

固定私有桶 `skill-packages` 的 `staging/{owner}/{upload}.zip` 用于暂存，`releases/{skill}/{release}.zip` 用于交付。API 角色被限制性 Storage policy 阻止直接访问；带授权的下载由服务端签发。文件不能作为本站同源 HTML、SVG 或脚本页面执行。

上传票据有效 24 小时，每站主最多同时 3 项、每小时 30 次；确认租约 2 分钟、最多 10 次。过期一小时、无确认任务且无已发布版本引用的文件可分批清理；历史版本不参与清理。

## 访问与交易

介绍公开；完整清单、文件与文本对话须登录且通过 `can_use_skill`。允许免费 Skill、有效订阅、直接购买或站主；迁移对象还接受原 `series` 权益。时间区间与撤销状态均在服务端检查。

SKU 为 `skill`，目标为介绍文章 ID。价格由 `skills.price` 快照；必须已发布、有当前版本且价格大于零。没有包不出售，暂停不新售，既有合法权益仍可使用；归档遵循三个月时间闸。结算、重复回调、权益和邮件沿用现有支付事务。详见 [支付契约](payment-api.md)。

| 接口 | 身份与行为 |
|---|---|
| `GET/POST /api/admin/skills` | 站主；修改另验 Cookie / Origin；上传、确认、配置 CAS、版本查询与过期清理 |
| `POST /api/skills/delivery` | 已登录账户 + Origin；每次复核版本权益后签发下载、安装授权或撤销本人的授权 |
| `POST /api/skills/install` | 请求头 `Authorization: Bearer wsi_…`；兑换指定不可变版本 |
| `GET/POST /api/skills/chat` | 已登录账户；读取本人会话，提交另验 Origin；客户端不能提交模型历史 |

安装授权只存摘要，15 分钟到期、可撤销，每份最多兑换 6 次；每人每小时最多签发 30 份。兑换重新验权，Storage URL 最长 60 秒且不超过授权剩余时间。令牌不放页面地址；结果 `no-store`、`no-referrer`。前台下载与安装入口放在 Skill 专属右栏；启用在线能力时提供地球图标和“切换成在线测试”入口，在线模式以电脑图标切回下载安装。模式在当前页右栏内切换，不替换介绍正文；消息气泡、输入和滚动布局与分身共用，Skill 的请求、会话及权限仍独立。平板使用右侧抽屉，手机使用底部 SKILL 入口。切换模式、主题或关闭抽屉不丢失本页输入和会话；只切换界面不发起模型请求。旧 `/skills/[slug]/chat` 地址转到介绍页并打开在线模式，有效会话 ID 保留，读取历史仍须本人身份。安装说明明确提示发送给所用 Agent，提供一键复制；复制失败保留可手动选择的文本。安装说明包含版本、摘要、文件清单和目标目录确认，不自动执行脚本。已签发 Storage URL 到期前可能有效，已下载文件不能远程收回。

## 文本执行边界

使用 AI 设置中的生成连接和共同的网络检查、协议适配、用量账本，不依赖全站 embedding。宿主规则固定边界；包指令、用户消息、资料及 `allowed-tools` 字段不能授予权限。

唯一工具为读取服务端绑定包的允许文本文件：UTF-8、无 NUL 的 Markdown、文本、JSON、YAML、CSV、TSV，单份 ≤32 KiB。脚本和二进制不作为可读工具。`SKILL.md` 超过 32 KiB 时只供下载，不静默截断核心指令。

每轮 ≤3 次模型请求、≤6 次文件读取，总请求 ≤128 KiB，整体 45 秒。通过受限 JSON 协议表达读取或回答；其他 AI 模块仍拒绝工具调用。每个模型子调用单独记账，派发后未知结果不自动重试。不提供 Shell、任意 URL、数据库、写文件或跨包读取，也不自动查询全站知识库。

受限协议由宿主请求输出格式：Chat Completions／Responses 使用 JSON 模式，Anthropic Messages 使用原生 JSON Schema 输出，不以隐式工具调用代替。SDK 解析后仍由执行器检查唯一动作字段、参数、包内路径与权益；合法 JSON 不等于获得工具权限。模型或协议不支持所需格式时明确失败，不自动降级重发。普通分身与页面生成仍使用各自原有输出方式，不新增配置变量。

失败响应提供本轮参考编号。服务端只记录该轮编号、至多三次模型子调用编号、固定错误码、供应商 HTTP 状态及是否派发；不记录账户标识、问题、包正文、密钥或原始异常文本。站主可按参考编号精确定位子调用，无须按用户与时间窗口扫描其他会话。日志失败不能改变原有的失败与不重试行为。

会话绑定账户、Skill 和不可变版本，最多 30 轮，同一会话一次只运行一轮。历史消息由服务端读取；重复请求返回已保存状态，改内容复用 ID 拒绝。每轮、每次读取及返回前重新验权。权限失效不再返回旧上下文。内容私有，不进入公开问答与索引；回答按不可信 Markdown 渲染，不执行 HTML、不自动加载模型图片。

轮数与上下文容量分别限制：不足 30 轮也可能因资料或历史过长触及单轮容量。系统不静默删减历史；长期工作流应在阶段完成时整理可带走的进度摘要，再按需新建会话接续。离线多轮回归验证历史传递与边界，真实验收须包含连续追问、补充、修正和最终交付，不能以几次独立问答代替。

## 旧内容兼容

旧 `collection` 保留 ID 转为手册；`/collections` 保留重定向。旧 Skill 系列经显式转换创建公开介绍并记录固定 `legacy_series_id`，只复制原本公开且同归属的 README，不复制付费章节。原标题、旧章节链接与交易目标保持可追踪。

旧系列与新 Skill 的暂停／恢复／归档同步，已购权益继续可用。旧订单和价格快照不改写；迁移前订单的迟到与重复结算仍走原 authority。没有有效包时不新增售卖入口。操作顺序见 [数据库升级](../operations/database-upgrade.md)。
